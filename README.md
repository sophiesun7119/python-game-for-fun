# Python Quest 🐍

A free, child-friendly way to practice real Python — built by a software-engineer mom for her Huaxia Chinese School Python class, and open to any kid who wants to learn how code actually runs.

**▶ Play now: https://sophiesun7119.github.io/python-game-for-fun/** — no downloads, no accounts, no passwords. Pick a nickname and start.

## What's inside

- **160 questions** in two challenges: **Challenge 1** (Weeks 1–4: printing & variables, logic, loops, functions) and **Challenge 2 — Data Explorer** (Weeks 6–9: lists, strings, sets, dictionaries)
- **4 levels per topic** — Easy, Medium, Hard, Extra Rock — 5 questions per quest, with XP, stars and topic badges
- **👀 Watch How the Code Works**: every question comes with a step-by-step walkthrough that runs the code line by line — watch variables change and output appear, exactly as real Python does it
- **Learn from mistakes**: hints and retries still earn full XP; bonus follow-up questions and 🐛 bug-hunt challenges on the harder cards
- **Leaderboard**: a friendly total-XP top 10 on the home screen (nicknames only)

Progress is saved per nickname in the same browser, and quests auto-save — leave and pick up right where you stopped.
